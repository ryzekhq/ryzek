Partnerships

Working together on agent security.

A few kinds of collaboration are genuinely useful right now. Others are not yet — this page is honest about which is which.

What's useful right now

Security research

If you're researching agent-skill or MCP attack surfaces and want a detection rule built around a finding, that's the fastest way to get one shipped. Turnaround is days, not release cycles.

Skill and MCP publishers

If you maintain skills or MCP servers that others install, running ryzek against them before publishing costs nothing and catches the classes of issue that reviewers miss. Happy to help interpret results.

Tooling integration

If you build an agent host, IDE plugin, or CI product and want scanning built in, the CLI is designed to be embedded — SARIF output, machine-readable JSON, and exit codes that behave sensibly in a pipeline.

Teams evaluating it seriously

If you're weighing ryzek for real use and need something it doesn't yet do, say so directly. Requests from people actually using the tool shape the roadmap more than anything else.

What isn't a fit yet

Ryzek is a small independent operation. That rules some things out for now, and pretending otherwise would waste your time:

Reselling or white-labelling — the BUSL-1.1 licence prohibits commercial resale and competing hosted services. Commercial licensing may be possible; ask, but expect a real conversation rather than a form.

Enterprise procurement with strict SLA requirements — formal SLAs are available on Enterprise terms only, and not on the standard plans. If your process requires a contractual response time before evaluation, say so up front and we will tell you honestly whether we can meet it.

Co-marketing arrangements — the honest answer is that ryzek has no audience to trade yet, so this would be one-directional.
