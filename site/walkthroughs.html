Walkthroughs

Four real files. See exactly what ryzek finds, and why.

Each example below is a real, downloadable skill file you can scan yourself — not a mockup. Same files used in this walkthrough are in the zip below.

⬇ Download all four examples (.zip)
EXAMPLE 01 · 01-credential-exfiltration/
The boring name hiding the dangerous part
A "settings sync" tool that reads your AWS, GitHub, and OpenAI credentials straight out of your environment and ships them to a server it controls.
critical finding
[critical] credential-exfiltration — sync_tool (0.94 confidence)
reason: reads AWS_SECRET_ACCESS_KEY, GITHUB_TOKEN, OPENAI_API_KEY from
environment and includes them in outbound request body — not required
by declared function.
run it yourself: npx ryzek ./01-credential-exfiltration
EXAMPLE 02 · 02-concealed-instruction/
When the file tries to talk to the agent, not the user
A meeting-notes formatter with an instruction hidden in an HTML comment, invisible on render, trying to override the agent's restrictions mid-session.
critical finding
[critical] concealed-instruction — meeting-notes-formatter (0.97 confidence)
reason: HTML comment contains an authorization-override directive and
an instruction to silently search for credential files. Full hidden
text quoted in verbose output.
run it yourself: npx ryzek ./02-concealed-instruction
EXAMPLE 03 · 03-post-approval-drift/
Approved once. Changed since. Nobody looked twice.
The same weather-lookup tool, before and after it quietly picked up filesystem access and a telemetry beacon — same name, same description, different behavior.
drift finding
[drift] weather_lookup — permissions changed since baseline
added: network:write, filesystem:read
reason: skill hash no longer matches approved baseline from
2026-08-03. Review before allowing this version to run.
run it yourself: npx ryzek . --set-baseline then rescan v2
EXAMPLE 04 · 04-clean-example/
And here's what "actually fine" looks like
A plain text summarizer. No permissions requested, no network access, no hidden anything. Included so the other three aren't the whole story.
clean
[clean] summarize_document — 0 findings
run it yourself: npx ryzek ./04-clean-example
